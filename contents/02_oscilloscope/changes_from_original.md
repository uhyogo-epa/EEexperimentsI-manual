# 交流回路（オシロスコープ）：原本からの変更点

原本：`実験手引書_交流回路(オシロスコープを用いた測定).docx`，説明資料 `交流回路（オシロスコープを用いた測定）.pptx`
対象ファイル：`oscilloscope_body.tex`，`oscilloscope_worksheet_body.tex`

## 構成
- 原本の節「実用例（音源(PC)から高音成分を除去し，スピーカーから出る音で確認）」をなくし，「目的」の後に本実験の趣旨の説明として書き直した（文章は新しく書いたので要確認）。説明資料18枚目「フィルタ回路を使用したデモ実験」の図を追加
- 節「オシロスコープとファンクションジェネレータの使い方」を新しく追加した（説明資料7〜15枚目の要点：使用する機器，プローブの準備と接続，注意点，ファンクションジェネレータの操作，練習）
- 節の順番を「目的 → オシロスコープとファンクションジェネレータの使い方 → 原理 → 使用器具 → 実験方法」にした（機器の使い方を先に）
- 「目的」の前半（原本は1文）をふくらませ，機器の使い方の習得，フィルタ回路の周波数特性の測定，フィルタとは何かを説明した
- 原理「交流」の最後の2文（オシロスコープで測定すること，オシロスコープの説明）を削除し，オシロスコープの説明は新しい節の冒頭に移した
- 「・交流」「・RC回路」「・RLC直列共振フィルタ回路」「・カットオフ周波数」の4つを，新しく設けた節「原理」の下にまとめた（テスターと構成をそろえるため）
- 「使用器具」を枠（equipment）で囲んだ
- 手順は原本の番号（1-1，1-2，1-3，2-1，2-2）のまま，番号付きの手順（procedure）にした
- 原本の最後にあった2つの記録表を，学生が記入する記録用紙（`02_oscilloscope_worksheet.tex`）に分けた
  - 表のタイトル「実験1：RCローパスフィルタの特性」「実験2：RLC直列共振フィルタの特性」は新しく付けた
  - 各表を「(a) 指定の測定点」（教員が周波数を指定）と「(b) 追加の測定点」（学生がグラフを見ながら周波数を決めて書き込む空欄6行）に分けた
  - 実験1の指定の測定点は 20 Hz から：20，50，100，200，…，1000 Hz（原本は 1，10，100，…，1000 Hz。カットオフ周波数が約 160 Hz なので 50 Hz を追加）
  - 1-2 のカットオフ周波数，2-2 の共振周波数の記入欄を追加
- 「実験方法」の冒頭に「測定結果は，ワークシートの表に記録してください。」を追加した

## 表記・文体
- 注意の枠の中の2点（グランド側同士をつなぐこと，指示がなければ 1:1 で使うこと）に波線（`\wave`）を追加
- である調 → です・ます調
- 句点「．」→「。」
- 数式は番号付きの式にした（カットオフ周波数の式，共振周波数の式）
- 変数を数式で表記（$R$，$C$，$L$，$V_\mathrm{m}$，$f_\mathrm{c}$ など）
- 共振周波数の記号 $f_\mathrm{o}$（オー）→ $f_0$（ゼロ）
- 単位付きの数値を `\SI{}{}` で表記

## 図
- 原本の画像ファイルをそのまま使用。キャプションは `\caption` で付け直した

## 内容の修正
- 誤字の修正
  - 「高音成分**の**除去し」→「高音成分**を**除去し」（見出し）
  - 「ある**特性の**周波数」→「ある**特定の**周波数」
  - 「減衰させる境界となり周波数」→「減衰させる領域の境界となる周波数」
  - 「ブレ**ット**ボード」→「ブレ**ッド**ボード」
  - 「0.1 uF」「1 uF」→「0.1 μF」「1 μF」
- 文の整理
  - 「電圧，電流の大きさ**は**正弦波状に変化するもの」→「大きさ**が**」
  - 「絶対値のなかで最も大きいもの」→「絶対値が最も大きいもの」
  - 共振の説明の「〜等しくなり，この状態を共振といい」を2文に分けた
- 手順1-1・2-1の「交流電源の電圧を10 Vに設定」→「交流電源の出力を振幅10 V（ピークピーク値20 V）に設定」（説明資料16枚目に基づく）
- 実験2の抵抗「10 Ω（茶黒黒金）」→「100 Ω（茶黒茶金）」（100 Ω が正しいと確認済み。使用器具の 100 Ω と一致）
- 図の参照を修正：手順1-1の「図4に示すような回路」→ 測定回路1（図6），手順2-1の「図5」→ 測定回路2（図7）
- カットオフ周波数の定義：原文「$f_c = 1/\sqrt{2} \approx 0.707$ となる周波数」→「出力電圧が最大値の $1/\sqrt{2}\approx 0.707$ 倍となる周波数」（周波数の式として意味をなさないため。要確認）
