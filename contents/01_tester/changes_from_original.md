# テスター：原本からの変更点

原本：`実験手引書_テスター.docx`
対象ファイル：`tester_body.tex`

## 構成
- テーマのタイトルを「テスターによる電気測定」→「直流回路（テスターによる電気測定）」に変更（ガイダンス配布資料のスケジュールの表記に合わせた）
- 見出しの手書き番号（「２.１.」など）を削除し，LaTeX の自動番号（2.1 など）に置き換え
- 「使用する機器と使用方法」の機器リストを「使用器具」の枠（equipment）で囲んだ
- 実験B・C・Dの手順を，黒丸の箇条書きから番号付きの手順（procedure）に変更
  - 事前確認と実験A（測る対象を並べたもの）は黒丸のまま
- 「考察と課題」の3項目（1. 2. 3.）を小見出し（5.1〜5.3）に変更

## 表記・文体
- 特に重要な部分・安全上の注意に波線（`\wave`）を追加：誤った端子での測定によるヒューズ切れ，抵抗測定は電源を外して行うこと，交流測定は教員立ち会いでプローブの金属部分に触れないこと，USB 端子に直接プローブを当てるとショートの危険，コンセントの測定は教員立会い（原本には波線なし）
- である調 → です・ます調
  - 「〜である。」→「〜です。」，「〜する。」→「〜します。」
  - 「〜せよ。」→「〜してください。」
  - 「〜すること。」→「〜してください。」
  - 「工夫してよい」→「工夫してかまいません」
  - 「以下の点に注意する：」→「以下の点に注意してください。」
- 全角数字（図１，第１帯，４本 など）を半角に統一
- 単位付きの数値を `\SI{}{}` で表記（例：100Ω → `\SI{100}{\ohm}`）
- 変数を数式で表記（$V_0$，$V_{1\,\mathrm{k\Omega}}$，$R_0$ など）
- 太字の語句は `\important{}` で表記
